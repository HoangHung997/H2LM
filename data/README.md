# H2LM data directory

Repository chỉ lưu schema, manifest và sample nhỏ.

Không commit trực tiếp:

- bộ PDF lớn;
- scan gốc dung lượng lớn;
- checkpoint;
- teacher output chưa lọc;
- dữ liệu có điều kiện sử dụng không cho phép phân phối.

Dataset production sẽ được tham chiếu bằng manifest có checksum và provenance để tái lập training run.
